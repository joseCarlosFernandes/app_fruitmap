🍎 Fruit Map

Fruit Map é um aplicativo de mapeamento colaborativo que permite aos usuários localizar e cadastrar árvores frutíferas espalhadas pela cidade e região.

A proposta é criar um mapa interativo e compartilhado, no qual qualquer usuário possa descobrir a localização de árvores e pés de frutas próximos, incentivando o compartilhamento de recursos naturais e o aproveitamento de frutas disponíveis na comunidade.

🌳 Funcionalidades

Mapa interativo: visualização dos pontos cadastrados em um mapa.

Cadastro de árvores frutíferas: permite registrar árvores e pés de frutas encontrados pela cidade ou região.

Localização dos pontos: o cadastro pode ser realizado estando fisicamente no local da árvore ou informando seu endereço.

Ícones personalizados: cada árvore é representada no mapa por um marcador personalizado de acordo com o tipo de fruta.

Mapa colaborativo: os pontos cadastrados ficam disponíveis para todos os usuários, permitindo que a comunidade compartilhe informações sobre árvores frutíferas

🛠️ Tecnologias utilizadas

Kotlin

Android Studio

Firebase (Authentication e Cloud Firestore)

Google Maps API
